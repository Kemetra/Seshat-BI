## Workstation setup this implies

These are the concrete, still-current bits worth acting on.

| Item | Why it matters here |
|---|---|
| **CodeScene MCP** | Seshat PRs run a CodeScene "new code is healthy" DELTA gate. Install via `/plugin`; needs an org CodeScene account/token. Running `analyze_change_set` locally before pushing is the documented pre-flight. |
| **`/model`** | Opus for synthesis and review, Sonnet for mechanical work. |
| **`/effort`** | Reasoning effort / orchestration mode. |
| **`/speckit-specify`, `/speckit-analyze`** | Front and consistency-check of the spec-kit chain, used for feature work. |
| **`/plugin`** | Installs the CodeScene MCP and the `seshat-bi` plugin. |
