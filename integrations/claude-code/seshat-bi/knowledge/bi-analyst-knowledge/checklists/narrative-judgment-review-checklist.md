# Narrative Judgment Review Checklist

## Grounding

- [ ] Every question/callout cites approved contracts and current revision SHAs.
- [ ] Source-profile revision and available dimensions are cited.
- [ ] No metric meaning, source fact, target, threshold, or number is invented.
- [ ] Unanswerable nodes are `[GAP]` with missing fact and unlocking feed.

## Analytical judgment

- [ ] Overview headlines carry a named comparison.
- [ ] Guardrail-bearing claims state basis, window, and sample floor where applicable.
- [ ] Diagnostic tree follows overview -> change -> driver -> segment -> exception -> action.
- [ ] Questions are ordered by owner decision relevance and evidence availability, not a score.
- [ ] Story order remains overview -> change -> why/where -> action.

## Change and action

- [ ] Contract/profile drift names affected question IDs and exact consequences.
- [ ] Narrative-change verdict is `unchanged`, `revise`, or `blocked` with evidence.
- [ ] Action handoff names a supplied owner role, decision, trigger, cadence, refresh, and
  escalation condition.
- [ ] No owner is appointed or approval self-granted.
- [ ] Layout, chart choice, rendering, and metric implementation remain downstream.

## Terminal result

Return findings, evidence, `[GAP]`s/blockers, and next action. This checklist supports human review;
it does not grant narrative, dashboard, readiness, or publish approval.
