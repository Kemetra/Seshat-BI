# Data model: dbt ownership

- **Intent route**: user intent, Seshat pre-gate, execution owner, Seshat return.
- **Seshat adapter**: governed wrapper with explicit delta; no native dbt semantics.
- **Official skill capability**: dbt Labs competence surface; activation deferred.
- **Official MCP capability**: dbt Labs tool surface; activation deferred.
- **Activation blocker**: installed is not equivalent to discoverable.
